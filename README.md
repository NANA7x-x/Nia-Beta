# Nia β版

個人の活動・制作・生活記録とOBS配信パーツを管理するローカルアプリです。まずMac・Windowsのアプリ版を提供します。Web版の端末間共有・共同編集は後続対応です。

[最新版のダウンロード](https://github.com/NANA7x-x/Nia-Beta/releases) · [使い方](BETA-START.md) · [対応状況と制限](BETA-LIMITATIONS.md) · [保存と外部接続](BETA-PRIVACY.md)

ZIPを展開してアプリを起動すると、普段のブラウザーで操作できます。Python・Node・Codexは不要です。データは各利用者の端末の専用DBに保存します。YouTube・Google接続は任意です。

**検証版です。** OS署名・公証は未設定で、端末により起動がブロックされる場合があります。実配信のリアクション受信等には未検証の部分があります。重要なデータは別途バックアップしてください。

こちらは配布ファイルと案内専用の公開リポジトリです。開発者の保存データ・認証情報・非公開ソースの履歴は掲載しません。

不具合・要望は [Issues](https://github.com/NANA7x-x/Nia-Beta/issues) へ。公開欄のため、個人情報・秘密値・接続用URL・ログやDB全体を投稿しないでください。
